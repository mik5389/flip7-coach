The recommendation is risk-neutral: it compares banking now with the exact expected score after one more card, using every revealed card at the table. It assumes a Freeze or Flip Three can be passed to another active player; special forced-draw tactics are not priced in.

Quick setup

  • Select a player, then tap every card revealed for them.
  • Tap a player’s status to cycle Active → Stayed → Busted.
  • New round automatically adds every player’s round score to their game total, then clears the hands.
  • Click a player’s Game total number if you ever need to correct it manually.
  • Change Winning score before the game ends if you want a target other than 200.
  • When the highest total reaches the target after a round, the game ends and displays final statistics.
  • Reshuffle discards puts all previously discarded cards back into the draw pile while leaving the current hands and round untouched.
  • For action cards, add the card to the player affected. Mark a frozen player as Stayed.

Hit once is the average value of every possible next card, after which you can decide again. With Second Chance, a duplicate consumes it instead of busting.
